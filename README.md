# 谷雨 · 雨亭养肤计划

完整桌面与手机适配的独立概念网站。设计字体、图片、样式和交互均内嵌在 `index.html`，可下载后直接在浏览器打开。

## 功能

肤况问答、规则演示方案、成分查询、产品资料与已购建档、独立产品手记、观察日历、曲线、备份、反馈导出及可拖拽小伴。

## 发布

在 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)，保存。以 GitHub 返回的实际网页地址为准。

非谷雨官方服务。AI内容为本地规则演示，不构成医学诊断；产品版本与使用说明应核验官方资料。资料仅保存在当前浏览器，不自动上传。GitHub Pages 在中国大陆的访问可能因网络而异。

字体采用 Noto Serif SC 与 LXGW WenKai，OFL许可已保留在网页源码中。图像及品牌标识的第三方权利仍归相应权利人。
